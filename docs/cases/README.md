# PhaseFlow cases

The case matrix contains thirteen scenarios across published MineLib deposits, declared MineLib scenarios, seeded
synthetic deposit geometries, operating regimes, and controls. The [case index](../cases.md) compares their scale,
scenario inputs, and execution lanes. The numbered pages in this directory record each case's source, assumptions,
certified bound, feasible methods, controls, and measured limits.

The published `newman1` instance is the trust anchor. Synthetic twins are generated from fixed seeds and can carry
block-level replay data. MineLib cases carry aggregate results only; the academic source files are not redistributed.
